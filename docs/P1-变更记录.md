## P1-01　T-07(a) 演示保护：演示模式 + 缓存落盘

- **目标**：现场网络差/断外网时演示不翻车（用户确认先做 a：能连服务器，但外网可能不通）。
- **改前**
  - 预置场景结果只在**内存**缓存，重启就没了，要重新调 AI 预热。
  - 所有提取都走在线 AI，断外网就只剩规则回退（无"演示模式"概念、无提示）。
- **改后**
  1. **缓存落盘**：预置/命中的提取结果写入 `cache/extract-cache.json`（带 `schemaVersion`，版本不符自动失效）；启动先读回磁盘，**重启即用、冷启动秒出**。
  2. **演示模式**：URL 带 `?demo=1`（前端传 `demo:true`）或服务端 `DEMO_MODE=1` → **不调在线 AI**，只走「预置缓存 / 本地规则」；响应 `mode` 标为 `demo-cache` / `demo-rules`。
  3. **前端提示**：演示模式顶部显示黄色横幅「🎬 演示模式：结果来自预置缓存 / 本地规则引擎，不调用在线 AI，断网也能演示。」；模式标签显示「演示模式 · 本地」。
- **位置**：`server.cjs`（缓存落盘 `persistCache/loadCacheFromDisk`、extract 分支、`/health` 增 `demoMode/cacheEntries`）；`index.html`（`DEMO_PARAM`、请求带 `demo`、横幅、模式标签）；`.gitignore` 增 `cache/`。
- **影响面 / 风险**：① 演示模式绝不渗进正常路径（只有 `DEMO_MODE` 或 `?demo=1` 才触发）；② 缓存落盘带版本校验，schemaVersion 变更自动失效；③ 不影响 `calc`/`schema` 口径（未改版本号）。
- **验证**
  - 单元测试 30/30；端到端 `scripts/verify-p0.sh` → **19/19**（新增【7】演示模式）
  - 缓存落盘实测：生成 5 条 → 重启日志 `loaded 5 entries from disk` → 预设请求 `X-KZ-Cache: hit`（未调 AI）
  - 演示模式实测：`?demo=1` 页面显示横幅、无 JS 报错；`demo:true` 请求返回 `mode=demo-rules` 且字段正常
- **现场用法**
  - 推荐：用 `https://wyzyw.icu/kaizhangqian/?demo=1` 演示（只影响这一次打开，别人不受影响）
  - 或：服务器设 `DEMO_MODE=1` 强制全局演示模式（仅会场临时用）
- **部署**：已合入 `main` 并 `pm2 restart`（见文末记录）
- **核对结果**：☐ 通过
