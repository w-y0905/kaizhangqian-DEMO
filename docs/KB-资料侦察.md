# 开张前 · 场景成本知识库（KB）资料侦察

> 目的：摸清「校园微创业各场景成本」能拿到多少资料，据此决定 KB 的规模与做法。
> 结论先行：**有零散经验数据，无权威结构化数据集** → KB 只能「人工整理 + 标注来源 + 仅作提示」。

---

## 一、侦察结论

| 维度 | 结果 |
| --- | --- |
| 权威数据（统计年鉴/研究报告） | ❌ 没有校园微创业细分场景的成本数据 |
| 半权威（新闻报道、行业报告） | 🟡 少量（如柠檬茶成本报道） |
| 经验数据（小红书/知乎/B站/自媒体） | 🟢 较多，但零散、口径不一 |
| 可得结论 | 可整理出**参考区间**，但**每个数字都必须标"参考、待用户确认"** |

**因此 KB 的定位**：不是"数据源"，是"**提示与追问的燃料**"。做法仍是结构化 JSON（不用 RAG）。

## 二、用途边界（关键，防止违反核心原则）

KB **只用于**：
1. 给 AI 注入场景上下文，让追问更专业、更贴场景；
2. 规则回退时生成专业追问；
3. 前端显示「合理区间」提示（如"杯成本通常在 1–3 元，你填的 8 元偏高了？"）。

KB **绝不**：
- 自动把参考值填进用户字段（必须保持"AI 不猜数字、数值由用户确认"）；
- 作为计算结果依据。

### 1. 饮品（柠檬茶 / 手打茶）
| 项 | 参考 | 备注 |
| --- | --- | --- |
| 单杯成本 | 1–3 元〔源〕 | 小红书经验帖可低至 1–1.2 元 |
| 包装耗材 | 约 0.5–1 元/杯〔源〕 | 有报道称一次性杯+吸管+袋约 0.8 元 |
| 摊位费 | 0–600 元/月〔源〕 | 校园免费/低价居多 |
| 设备投入 | 200–1500 元〔源〕 | 简易摆摊<200，含推车/保温箱约 1500 |

| 定价 | 8–20 元/杯〔源〕 | 校园多在 6–10 元 |

**易漏项**：鲜果损耗、杯子/吸管/封口膜、摊位/校园准入费、备料工时。

## 四、可整理成的 KB 结构（草案）

```
kz-scene-kb.js（纯数据 + 查询，kbVersion）
scene(key) -> {
  label, unit,
  costItems: [{ key, label, rangeText, note }],   // 常见成本项 + 参考区间
  commonlyMissed: [ '损耗', '备料工时', ... ],      // 易漏项
  questions: [ ... ],                              // 场景化追问
  pricingRange: '6–10 元/杯'
}
```
三个用途接入点：① `buildPrompt` 注入摘要；② `sceneQuestions` 用 KB 生成；③ 前端字段旁显示区间提示。

## 五、覆盖范围（已定）

用户要求：**多覆盖一些场景**。因此 KB 覆盖：
- 5 类预设（饮品/零售/技能/创意/其他）
- **新增**：跑腿代取、宿舍美甲、夜市小吃、打印复印、手机贴膜、宠物代养/遛狗、二手转卖（低置信，仅追问）
- **自定义场景兜底**：关键词匹配到最近场景；匹配不到则用通用追问模板

仍需你确认：区间数字按「仅供参考、待用户确认」口径展示（不会自动填入）。

确认后我再动手写 `kz-scene-kb.js`（先写数据 + 测试，再接三处，最后跑全预设回归）。
